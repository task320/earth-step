# EarthStep アセット発注仕様 (P6)

制作者へ渡す用の仕様。仕様書は [docs/spec.md](./spec.md)、タスクは [docs/TASKS.md](./TASKS.md)。

アプリは P5 まで実装済みで、**素材が無い状態でも動く**ようになっている。
現状は代替表示（等幅フォント・手書きの粗い地図・Material の既定アイコン・無音）で、
納品された素材に差し替えると見た目と手触りが上がる、という位置づけ。

---

## 0. 全体に共通するルール

| 項目 | 内容 |
|---|---|
| 画風 | ドット絵（ピクセルアート）。SFC/GBA 時代のRPG風 |
| グリッド | 32×32px を基本。アイコン類はこの倍数か約数で作る |
| 色 | 下記「限定パレット」の17色**のみ**を使う。中間色・グラデーション・半透明を使わない |
| アンチエイリアス | **必ずオフ**。輪郭をぼかさない。書き出し時の再サンプリングも禁止 |
| 拡大 | 等倍（1ドット=1px）で作る。アプリ側がニアレストネイバーで整数倍に拡大する |
| 角丸 | 使わない。UI部品はすべて直角 |
| 1ドットの表示サイズ | 4dp。つまり 32×32px の素材は画面上 128dp 四方になる |

> **アンチエイリアスの禁止がいちばん重要**。1px でもぼけた輪郭が混ざると、
> 拡大したときにその部分だけにじんで見える。書き出し設定を必ず確認してほしい。

## A. 効果音（P6-2）

3種。仕様5.3 のとおり、演出は「通常」と「大台」の2段階しかないので音も絞る。

| ファイル名 | 用途 | 長さの目安 | 性格 |
|---|---|---|---|
| `se_milestone.ogg` | 通常のマイルストーン到達 | 0.3〜0.6秒 | 短く軽い。1日に何度も鳴るので主張しすぎない |
| `se_major.ogg` | 大台（地球一周・周内25/50/75%） | 1.5〜2.5秒 | 生涯に数回しか鳴らない。ファンファーレ寄り |
| `se_tap.ogg` | ボタン操作 | 0.05〜0.15秒 | ごく短いクリック音 |

**技術要件**

- 形式: OGG Vorbis（推奨）または WAV（16bit PCM）
- サンプルレート: 44.1kHz、モノラル
- ピーク: −3dBFS 以下（端末スピーカーで割れないため）
- **先頭の無音を入れない**。達成の瞬間とズレて聞こえる
- ファイル名は**小文字の英数字とアンダースコアのみ**（Android のリソース名の制約）

**置き場所**: `app/src/main/res/raw/`

**音の方向性**: 8bit/チップチューン系。ドット絵の画風に合わせる。
生録音や実楽器のサンプルは画面から浮くので避けたい。

**ライセンス**: 商用利用可・改変可のもの。効果音ラボ、魔王魂などのフリー素材でよい。
**出典とクレジット表記の要否を必ず添えること**（項目Gに記載）。

## B. ドット世界地図（P6-3）

いま入っているのは私が手で起こした 72×36 の概形で、海岸線は正確ではない。これを置き換える。

**要件**

| 項目 | 内容 |
|---|---|
| 図法 | 正距円筒図法（equirectangular） |
| 縦横比 | **横:縦 = 2:1 を厳守**。経度360度・緯度180度を等間隔に割る |
| 推奨サイズ | 144×72px または 288×144px（現状は 72×36px） |
| 横のつなぎ | **左端と右端がシームレスに繋がること**。周回のラップ処理がこれに依存する |
| 内容 | 陸と海の2値のみ。国境・地名・起伏は入れない |
| 色 | 塗り分けはアプリ側で行う。素材は形だけでよい |

**納品形式（どちらでも可）**

1. **PNG** — 陸を不透明（何色でもよい）、海を完全透明にした1枚。1px = 1ドット
2. **テキスト** — 陸を `#`、海を `.` とした行の羅列。1行が1緯度帯

テキストで受け取れば実装の差し替えが不要（現在の `WorldMapDots.kt` の配列をそのまま置換できる）。
PNG の場合はこちらで読み込み処理を書く。**どちらでも構わない**。

**赤道の位置**: 縦中央。現在は 36行中の18行目を赤道としてトレイルを描いている。
偶数行数なら「上から行数÷2 の行」を赤道として扱うので、その行が海だけにならないよう注意はいらない
（赤道上を東へ進む方式なので、陸の上をトレイルが通るのは正常）。

**出典**: Natural Earth（パブリックドメイン）のような、再配布可能な世界地図データからのドット化を推奨。
自作でも構わない。いずれの場合も出典を項目Gに記載してほしい。

## C. タブアイコン（P6-4）

画面下部のタブ4つ。現在は Material の既定アイコンを使っていて、ドット絵の画面から浮いている。

| 用途 | 現在の代替 | 図案の方向性 |
|---|---|---|
| ホーム | 家 | 家、または地球 |
| マップ | ピン | 世界地図、または旗 |
| 達成記録 | リスト | 巻物、チェックリスト |
| 設定 | 歯車 | 歯車、レンチ |

**要件**

- サイズ: 32×32px（24×24px でも可。4種で統一すること）
- 単色のシルエット。色はアプリ側で塗る（選択時 `#0B0E1A` / 非選択時 `#7C849C`）
- 背景は透明
- 形式: PNG（透過）または SVG

---

## D. 通知アイコン（P6-4）

常駐通知と達成通知に出る小さなアイコン。

- **単色シルエットとして描画される**。色や階調は無視されるので、塗りは1色でよい
- 背景は透明必須。地の部分が塗られていると四角い塊として表示される
- サイズ: 24×24dp のベクター（SVG）が理想。PNG なら 96×96px（xxxhdpi）1枚あれば足りる
- 図案: アプリの象徴（地球、足跡など）。細部は潰れるので単純に

現在は仮の地球アイコンが入っている（`res/drawable/ic_notification.xml`）。

---

## E. アプリアイコン（P6-5）

Android のアダプティブアイコン。前景と背景に分かれる。

| 項目 | 内容 |
|---|---|
| 背景 | **単色 `#0B0E1A` で確定済み**。素材不要 |
| 前景 | 108×108dp 相当のキャンバス。実サイズ **432×432px** の透過PNG |
| 安全領域 | **中央の 66×66dp（264×264px）に主要な図柄を収める** |
| 形式 | 透過PNG（432×432px）。ベクターでも可 |

外周は端末ごとのマスク（円・角丸四角など）で切り取られるため、
安全領域の外に重要な要素を置くと欠ける。

スプラッシュ画面は Android 12 以降このアダプティブアイコンの前景を流用するので、**専用素材は不要**。

| 素材 | 名称 | 作者 | 配布元URL | ライセンス | 必要なクレジット表記 |
|---|---|---|---|---|---|
| 例）通常達成音 | 〇〇 | 〇〇 | https://... | CC BY 4.0 | 「Sound: 〇〇 by 〇〇」 |

自作素材の場合も「自作」と明記してほしい。

## H. 別途判断が必要な項目（素材制作の依頼対象外）

### H-1. ドットフォント（決定済み）

仕様5.4 は Press Start 2P を挙げているが、**このフォントはラテン文字しか持たない**。
アプリの文言は日本語なので、そのままでは本文に使えない。

**PixelMplus12 を採用**(H-1最推奨案)。`https://github.com/itouhiro/PixelMplus` から取得し、
`app/src/main/res/font/pixelmplus12_regular.ttf` に配置。`pixelFontFamily`(`Type.kt`)を差し替え済み。
ライセンスは M+ FONT LICENSE(商用利用・改変自由、クレジット任意)。出典は `LICENSES` に記載。

**Boldは同梱していない**(実機検証で発見、2026-08-22)。配布元の `PixelMplus12-Bold.ttf` は
`m` などラテン文字グリフの輪郭データが壊れており(`cmap` は正しいが `glyf` の輪郭数が本来より少ない)、
実機で潰れた塗りつぶしとして表示される。累計距離のような太字表示の数値がまともに読めなくなるため、
Regular 1本だけを登録し、太字要求は Compose の合成太字(faux bold)に任せている。

### H-2. 大台演出の一言説明文

仕様3.4 の「実在物についての一言説明」が未執筆。素材ではなくテキストなので別枠。
現状は周内マーカー（25/50/75%）の説明だけ書いてあり、マイルストーン側は空。
最低限 #100（地球一周）の分があれば大台演出は成立する。

## 差し替え時の置き場所（参考）

| 素材 | 配置先 |
|---|---|
| 効果音 | `app/src/main/res/raw/` |
| 世界地図（PNG） | `app/src/main/res/drawable-nodpi/` |
| 世界地図（テキスト） | `WorldMapDots.kt` の配列を置換 |
| タブアイコン | `app/src/main/res/drawable/` |
| 通知アイコン | `app/src/main/res/drawable/ic_notification.xml` を置換 |
| アプリアイコン前景 | `app/src/main/res/mipmap-xxxhdpi/` ほか |
| フォント | `app/src/main/res/font/` |

`drawable-nodpi` を指定しているのは、密度ごとの自動スケーリングを避けるため。
ドット絵は端末の解像度に応じて勝手に拡大されると輪郭がぼける。

## 受け入れ時に確認すること

- [ ] パレット外の色が混ざっていないか（スポイトで数点抜き取って確認）
- [ ] 輪郭にアンチエイリアスがかかっていないか（拡大して中間色の画素が無いこと）
- [ ] 世界地図の左端と右端が繋がるか（横に2枚並べて継ぎ目が見えないこと）
- [ ] 世界地図の縦横比が正確に 2:1 か
- [ ] 効果音の先頭に無音が入っていないか
- [ ] 効果音のファイル名が小文字英数字とアンダースコアのみか
- [ ] アプリアイコンの図柄が安全領域（中央 264×264px）に収まっているか
- [ ] 通知アイコンの背景が透明か
- [ ] すべての素材について出典とライセンスが揃っているか
