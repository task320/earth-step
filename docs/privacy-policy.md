# EarthStep プライバシーポリシー

最終更新日: 2026年8月22日

本ポリシーは、アプリ「EarthStep」(開発者: tanutus、以下「本アプリ」)が取得する情報とその取り扱いについて説明します。

## 1. 本アプリの概要

本アプリは、ユーザーが実際に歩いた・移動した距離を計測し、地球一周(約40,075km)を目標に進捗を記録する記録用アプリです。距離の計測にはスマートフォンの位置情報センサーおよび歩数センサーを使用します。

## 2. 取得する情報

| 情報 | 取得目的 | 取得方法 |
|---|---|---|
| 位置情報(GPS、概略位置を含む) | 移動距離の計測 | 端末のGPS/位置情報サービス |
| バックグラウンド位置情報 | アプリを閉じている間も距離を計測し続けるため | 端末の位置情報サービス(常駐計測中のみ) |
| 活動状態(徒歩/自転車/車など) | 徒歩以外の移動を計測対象から除外するため | Google Play services Activity Recognition API |
| 歩数 | GPSが使えない屋内などでの距離推定、GPSの誤差補正 | 端末の歩数センサー |
| Googleアカウント情報(アカウントID・メールアドレス・表示名) | クラウド同期機能を利用する場合の同期先アカウントの識別 | Google Sign-In(ユーザーが同期機能を有効にした場合のみ) |
| クラッシュ・エラー情報 | 不具合の把握と修正 | Firebase Crashlytics |

本アプリは、氏名・住所・電話番号・決済情報などの入力は求めません。

## 3. 位置情報の取り扱い

- 位置情報は**移動距離の計算のみ**に使用します。訪問先の特定、行動履歴の分析、広告目的での利用は一切行いません。
- 計算に使った生の位置情報(緯度・経度)は、計算後にサーバーへ送信されることはありません。エラーログ・クラッシュレポートにも緯度・経度は含めない設計にしています。
- 位置情報の取得は、常駐計測がオンの間のみ行われます。

## 4. データの保存場所

- 計測した距離・達成記録・設定などのデータは、**すべて端末内のデータベースにのみ保存**されます。
- 通常の利用において、これらのデータが本アプリの開発者や第三者のサーバーへ送信されることはありません。

## 5. クラウドバックアップ(任意機能)

本アプリには、機種変更時などにデータを引き継ぐための任意のバックアップ機能があります。

- この機能はユーザーが**Googleアカウントでサインインし、明示的に有効化した場合にのみ**動作します。
- バックアップ先は、ユーザー自身のGoogle Driveの**アプリ専用領域(appDataFolder)**です。この領域はユーザーのDrive上の通常のファイル一覧には表示されず、本アプリ以外からはアクセスできません。
- バックアップされる内容は、日別の移動距離・達成記録・周回記録・歩幅の較正値など、本アプリの記録データのみです。
- バックアップ機能を無効化・Googleアカウントの連携を解除した場合、以後の自動同期は行われません。Google Drive上に残ったバックアップファイルを削除したい場合は、[Googleアカウントのアクセス権管理ページ](https://myaccount.google.com/permissions)から本アプリのアクセスを取り消してください。

## 6. 第三者サービス

本アプリは以下の第三者サービスを利用しています。

| サービス | 用途 | 提供元のプライバシーポリシー |
|---|---|---|
| Google Play services (位置情報・活動認識) | 距離計測 | https://policies.google.com/privacy |
| Google Sign-In / Google Drive API | クラウドバックアップ(任意) | https://policies.google.com/privacy |
| Firebase Crashlytics | クラッシュ・エラーの収集 | https://firebase.google.com/support/privacy |

本アプリは広告表示・広告SDK・アクセス解析(Google Analytics等)を組み込んでいません。

## 7. 情報の第三者提供

法令に基づく場合を除き、取得した情報を第三者に販売・提供することはありません。

## 8. データの削除

- **アプリ内**: 設定画面から進捗データ(距離・達成記録・周回)をリセットできます。
- **アプリのアンインストール**: 端末内に保存されたすべてのデータが削除されます。
- **クラウドバックアップの削除**: 上記5の手順でGoogleアカウントのアクセス権を取り消してください。

## 9. 権限一覧と用途

| Android権限 | 用途 |
|---|---|
| ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION | 距離計測(GPS) |
| ACCESS_BACKGROUND_LOCATION | アプリを閉じていても計測を続けるため |
| ACTIVITY_RECOGNITION | 徒歩以外の移動を計測対象から除外するため |
| FOREGROUND_SERVICE / FOREGROUND_SERVICE_LOCATION | 計測を常駐サービスとして動作させるため |
| POST_NOTIFICATIONS | 計測状況・達成通知の表示 |
| RECEIVE_BOOT_COMPLETED | 端末再起動後に計測を自動再開するため |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | バックグラウンドでの計測精度を保つため(拒否しても動作は継続します) |
| INTERNET | クラウドバックアップ機能(任意)の通信 |

## 10. 対象年齢

本アプリは特定の年齢層を対象としたものではなく、児童から意図的に情報を収集する機能は含まれていません。

## 11. ポリシーの変更
