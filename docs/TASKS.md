# EarthStep 開発タスク一覧

仕様書: [docs/spec.md](./spec.md)

本ドキュメントは仕様書を実装単位のタスクへ細分化したもの。
タスクIDは `フェーズ番号-連番` 形式。見積もりは1人日=8hの目安。

## 想定技術スタック(前提)

| 項目 | 選定 |
|---|---|
| 言語 | Kotlin |
| UI | Jetpack Compose |
| DI | Hilt |
| 非同期 | Coroutines / Flow |
| DB | Room |
| 設定保存 | DataStore (Preferences) |
| 位置情報 | Google Play Services Location (FusedLocationProvider) |
| 活動検知 | Play Services ActivityRecognition + Activity Transition API |
| 常駐 | Foreground Service (`foregroundServiceType="location"`) |
| 同期 | Google Drive REST API (AppDataFolder) + Credential Manager |
| minSdk / targetSdk | 26 / 最新 (Android 15+ の FGS 制限に対応) |

### P1 の実装メモ

| 決めたこと | 理由 |
|---|---|
| 日別距離の加算は `INSERT OR IGNORE` + `UPDATE ... SET distance_m = distance_m + ?` の2文 | SQLite の UPSERT (`ON CONFLICT ... DO UPDATE`) は 3.24 以降。minSdk 26 (Android 8.0 = SQLite 3.18) では使えない。2文をリポジトリのトランザクションで束ねる |
| `lifetime_stats` は `id` 固定の単一行 | 更新系をすべて UPDATE 文で書けるようにするため。行が無い場合は更新前に `INSERT OR IGNORE` で作る |
| 時刻・タイムゾーンは `AppTimeSource` 経由でのみ取得 | 日付境界をテスト可能にするため。タイムゾーンは実行中に変わるのでキャッシュしない |
| 当日距離の Flow は `DayTicker` で日付変更時に張り替え | 深夜0時に加えて最大1時間ごとに再確認し、タイムゾーン変更も拾う |
| マイルストーンの一言説明は `description: String?` を用意して全件 null | 文面が未執筆のため(下記 要確認事項1)。器だけ先に用意した |
| 達成の冪等化は PK + `OnConflictStrategy.IGNORE` | P4-3 の前倒し。DAO 側で二重記録が起きない状態にしておく |
| Room のスキーマJSONは `app/schemas/` へコミット | `SchemaExportTest` がバージョンとテーブル数を検証し、出し忘れをCIで落とす |
